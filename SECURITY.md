# Security Policy

Telltale makes no network connections and only reads local sensors. It collects no telemetry and never needs admin rights itself. That keeps the attack surface small, but reports are still welcome.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please use GitHub private vulnerability reporting: open the [repository](https://github.com/barraco002/telltale), go to the "Security" tab and choose "Report a vulnerability". The report stays private between you and the maintainer.

Do not open public issues for vulnerabilities. If the report is accepted, the fix is prepared privately and published with a note in `CHANGELOG.md`.
